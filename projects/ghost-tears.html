Ghost Tears: a word game for friends, redesigned in three themes on one system.

Ghost Tears is a turn-based word game for 3 to 6 friends: add a letter, but don’t finish the word. The client asked for a friendlier look, so I redesigned every screen, the mascot and the system underneath.

Role
Product designer · UX, UI, brand
Product

Status

32Colour tokensPer theme, same names
TL;DR
The problem

A party game has to be learned in seconds and read at a glance, and the earlier design felt colder than the game is.

The solution

A friendlier ghost, rounder type, and a game screen where whose turn it is and what to do are never in doubt.

My role

UX flows, UI for every state, the mascot and logo, and the token system that drives all three themes.

07 Looking back

What Ghost Tears taught me.

01

Design the turn first

Everything else in a turn-based game hangs off one screen. I settled that before the rest.

02

Name tokens by job

Because tokens are named for their role, a new theme is a new set of values, not new screens.

03

A mascot carries tone

Five small expressions did more for “friendlier” than any colour change.
