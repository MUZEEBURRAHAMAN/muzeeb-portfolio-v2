// Claude skills & automation

I turned the design reviews I repeat into reusable Claude skills.

I kept giving AI the same context, frameworks and rules. So I packaged the processes I trust into skills that run inside Claude Code, and each session starts from them.

01 The problem

Good AI output depends on the workflow around it.

Without a rule system, you repeat the same loop every session:

Explain contextPromptToken driftManual fixRe-promptReview
02 How I build a skill
01

Spot the friction

I watch for a prompting loop I repeat more than three times across reviews and handoffs.

02

Write the rules

I turn it into structured rules: W3C tokens, WCAG 2.2 checks, checklists and edge-case matrices, in Markdown and XML.

03

Package it

I bundle the rules into a .skill file that Claude Code runs, so I never re-explain the context.

03 Skills I ship
Design System ArchitectTurns interface screenshots into components, maps semantic tokens, checks state matrices and WCAG 2.2.
AI UX Audit AssistantReviews screens and live products for usability, hierarchy, contrast and missing states.
HonestlyMakes the model separate facts from assumptions and skip flattery.
Honestly ReviewA design-manager critique of type hierarchy, density and engineering feasibility.
04 What changed

Before Raw chat

  • Repeat context and format rules each time
  • Context → prompt → correct → review

After Skill runtime

  • Start from codified rules
  • .skill → context → output → my judgement

What I learnedWhen you write your design taste down as rules, the AI follows your craft instead of giving generic answers.

02 Token architecture

Three tiers keep design decisions reusable.

Hardcoded hex values and one-off margins cause brand drift. I structure tokens to the W3C Design Tokens (DTCG) format so they compile to CSS, iOS and Android.

01

Global primitives

Raw values: colour ramps, a modular type scale, grid multiples. Example: blue.600 = #0284c7.

02

Semantic tokens

Intent that changes with the theme, like dark mode or high contrast. Example: color.action.primary = blue.600.

03

Component tokens

Bindings that protect a component from global changes. Example: button.primary.bg = color.action.primary.

Figma VariablesStyle DictionaryCSS, Swift and Kotlin packages
03 Component standard

I design 7 states before handoff.

DefaultHoverPressedFocus-visibleDisabledErrorLoading

Each component also ships with keyboard behaviour and ARIA semantics. A component without its loading, error and focus states is not finished.
